# Supported fiat currency

Here is the fiat currency we currently support for transactions. We are working on adding more options in the future to give your users more choices.

| Name                      | Code |
| :------------------------ | :--- |
| Nigerian Naira            | ngn  |
| Ghanian Cedis             | ghs  |
| Central African CFA franc | xaf  |
| West African CFA franc    | xof  |
